Outlines

Session 1: basic setup for prototyping (30mins)

The goal for this session is to have the software, folder, files set up so that people can start prototyping with html/css by hand or with help from AI. Different methods for viewing, sharing and publishing the prototypes are also covered.

  • Software setup with
    • Code editor: VScode or cursor
    • Extensions inside the code editor
      • Live view
      • Claude Code / Codex IDE extension
  • Prototype file setup
    • Folder & file structure
    • Base HTML starter file
    • Base CSS file that provides typography, color, responsive grid settings based on the current nvidia.com pages.
  • Recruit an AI
    • Prototype with Claude / ChatGPT desktop app
      • Chatbot
      • Cowork / work
      • Code / Codex
    • Prototype with AI agent in software on harddrive
      • IDE extension: Claude Code / Codex
      • CLI: Claude Code / Codex
  • Ways to backup & publish
    • Drag & drop a folder on online cloud, open to public
      • cloudflare, vercel, github pages
    • Drag & drop on NVIDIA image server Akamai, open to public
    • Publish on AEM preview, require NVIDIA account
    • Publish on gitlab, require NVIDIA VPN
    • Local HTTP server

Session 2 (optional): Enhanced workflow (30min)

Please join us If you are curious about having a time machine that tracks your prototype versions, and engaging in social coding. In this optional session we will be making a statement when we stage a creative take over of Github & Gitlab. We will take advantage of the infrastructure designed for the developers, learn how to collaborate on projects, copy and edit other people’s prototypes.

  • Time machine (Git)
    • Set up local git
    • Create checkpoints / history in VScode and Terminal
    • The benefits of the Git + AI combo
  • Collaboration & social coding
    • Create a nerdy profile on Github / Gitlab
    • Link local git to a remote repo
    • Fetch / pull in the main branch
    • Commit / push in the main branch
    • Feature branch
      • Your own playground
      • Merge with the main branch through pull request
    • Fork
      • Collab with / copy / steal others files
  • Team activity: Ancient Mediterranean Timeline project
    • Set up a Github / Gitlab repo as a collaboration platform
    • Everyone will join the project repo as collaborators, filling in the history, story and drama of the major powers & people in the Mediterranean region in chronological order.
    • Pull other people’s change from the repo, commit and push your change to the repo sequentially

Session 3: AI projects (30min)

The last session provide an opportunity to examine how AI can help fill in the skill gap and automate things through the following 2 projects

  • AI Art Gallery
    • Bring in your “spiritual animal”, “dream travel destination”, and “micro world” AI art pieces created during the creative summit.
    • Use the provided template to put together a simple webpage that features our artworks
    • Continue to practice repo skills:
      • Create feature branch
      • Pull request to merge the feature branch to main branch
    • Publish on Gitlab/Github
  • Figma to webpage
    • Prepare a points scoreboard design in figma
      • Name the layers to assist AI interpretation
      • Provide states and interaction variations
    • In the coding software or terminal use AI to code the design based on the figma artboard
    • Use google sheet as a simple database to keep the scores submitted by the user
